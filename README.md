# Ashwanth133-BANKING-APPLICATION-BY-OOP-

🏦 Banking Application (Java)

📍Description :

This is a console-based banking application created using Core Java.
It allows users to create an account, login, deposit money, withdraw money, and check balance.
The project is made to understand basic Java and OOP concepts.

🚀 Features
Create account
Login using ID and password
Deposit money
Withdraw money
Check balance
Menu-based program


🧠 Concepts Used

Java OOP ---
Classes and Objects
Encapsulation
Basics Java with Collections



▶️ How to Run :

Open project in IntelliJ or Eclipse
Run Main.java
Follow the menu shown in console


🤓 Future Improvements
Add database

Convert to Spring Boot

This project helps in understanding Java basics and object-oriented programming.
